How to activate the bot

  1. Open the game in a separate tab.
  2. Install a browser userscript manager, such as Tampermonkey.
  3. Install a controller script that runs on the Hooda Math page.
  4. Test steering with the game visible before enabling automation.

Important: this dashboard does not yet detect obstacles or steer the game. That requires a game-side script with a reliable view of the game's state.
